05 / RESEARCH INTEGRITY

Calculation is not validation.

A numerical match between historical and modern values is meaningful only when their coordinate origins, reference frames, epochs, time scales and mean/apparent conventions are compatible.

V4 provides a general mathematical model. Historical parameters must be independently documented before the model can be attributed to a historical astronomical method.
